# Nivel1-Trilhas
Simula o caixa de uma loja aplicando descontos progressivos por idade (>=65 anos: 20%), valor da compra (>R$100: 10%) e cupom ("FIDELIDADE10": 10%). Registra cada venda em uma lista, trata valores negativos e encerra digitando 0, exibindo um resumo com total bruto, descontos e valor final do dia.
